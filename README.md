
## 🔧 Özelleştirme

### Renkleri Değiştirme
CSS dosyasındaki `:root` değişkenlerini düzenleyin:

```css
:root {
    --primary: #2563eb;
    --secondary: #7c3aed;
    /* ... */
}
```

### İçerik Güncelleme
HTML dosyalarındaki metin içeriklerini doğrudan düzenleyebilirsiniz.

### Yeni Bölümler Ekleme
